# جدول دوامي — Android

تطبيق أندرويد أصلي بلغة Java يعمل دون إنترنت.

## بناء APK
1. افتح مجلد `DawamiApp` في Android Studio.
2. دع Android Studio ينزّل Gradle/Android SDK المطلوبين ويُكمل Sync.
3. اختر Build > Build Bundle(s) / APK(s) > Build APK(s).
4. ستجد الملف عادة في `app/build/outputs/apk/debug/app-debug.apk`.
5. انقله إلى هاتفك وثبّته بعد السماح بتثبيت التطبيقات من هذا المصدر.

تبدأ الدورة يوم 2026-11-04: نهار، نهار، صباح، صباح، إجازة، إجازة. تنتهي 2030-01-01 شاملًا.

ملاحظة: خيار مشاركة CSV يشارك نص CSV يمكن حفظه بامتداد .csv. لا يوجد APK مبني ضمن الحزمة؛ البناء يحتاج Android SDK وGradle.
